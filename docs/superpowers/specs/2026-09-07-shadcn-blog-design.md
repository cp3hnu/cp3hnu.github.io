# shadcn/ui 博客设计

## 目标

完善 `docs/blog/2026-07-11-shadcn.md`，写成一篇面向初学者的中文教程。文章介绍 shadcn/ui 的定位与解决的问题，并带领读者完成新项目初始化、已有项目初始化、主题配置和组件管理。

## 内容结构

1. 用一句话概括 shadcn/ui，再说明它通过把组件源代码放入项目来解决传统组件库难以深度定制的问题。
2. 说明 shadcn/ui 与 Base UI、React Aria、Radix UI 的关系，区分组件分发方式与底层无样式组件。
3. 介绍 Shadcn/Create，使用表格完整列举当前页面提供的 Style、Base Color 和 Theme。
4. 介绍已有项目使用的 CLI 初始化方式，并解释初始化生成或修改的主要文件。
5. 介绍 CSS Variables、主题变量和暗色模式。
6. 介绍组件的添加、查看差异和删除方式。
7. 添加官方文档、Create、CLI、Theming 以及底层组件库的参考链接。

## 写作与验证要求

- 保留现有 frontmatter 和发布路径。
- 沿用仓库中技术博客的中文教程风格：先说明概念，再给出步骤、命令和解释。
- 命令、配置项和可选值以当前 shadcn/ui 官方文档及源码为准。
- Style、Base Color 和 Theme 的表格必须列全，不把旧版选项与当前 Create 选项混在一起。
- 不加入未经验证的版本号、默认值或兼容性结论。
- 只修改目标博客和这份设计说明，不改动其他已有工作区变更。

## 验收标准

- 读者能够理解 shadcn/ui 与传统 npm 组件库的区别。
- 读者能够选择合适的 Create 配置并完成新项目创建。
- 读者能够在已有项目中初始化 shadcn/ui、切换主题并添加组件。
- Markdown 结构、表格、代码块和链接可以被现有 VuePress 站点正确处理。
